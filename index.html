問題を増やす（任意）

このアプリには – 問が最初から入っています。それに加えて、手元にある問題を取り込めます。取り込んだ問題はこの端末のブラウザ内にだけ保存され、外部には送信されません。
方法1　問題ファイルを読み込む
下の形式で書かれた JSONファイルがあれば、そのまま取り込めます。ファイル名は何でも構いません。
ファイルの書き方を見る 
[
  {
    "id": "MY-001",
    "exam": "SAA-C03",
    "question": "問題文をここに書きます。",
    "n_correct": 1,
    "options": [
      {"letter":"A","text":"選択肢A","correct":true,
       "explanation":"正解です。理由をここに。"},
      {"letter":"B","text":"選択肢B","correct":false,
       "explanation":"不正解です。理由をここに。"}
    ]
  }
]
必須は id（重複しない文字列）／exam（試験ID）／question／options。
n_correct は正解の数（省略すると1）。explanation は省略できますが、あると復習に役立ちます。
複数の試験の問題を1つのファイルに混ぜても構いません（exam で振り分けられます）。

キーはこの端末のブラウザ内にだけ保存され、送信先は選んだモデルの提供元（AnthropicまたはOpenAI）のAPIだけです。キーがなくてもAI以外の全機能を使えます。

学習設定

同じ問題を繰り返すとき「正解はB」と記号で覚えてしまうのを防ぎます。本番同様、内容で判断する練習になります。
習得済みの問題を 1日 → 3日 → 7日 → 14日 → 30日 の間隔で自動的に再出題します(忘却曲線対策)。間違えると間隔はリセットされます。
区切りとして結果をまとめる単位です。「問題を解く」では回答が1問ごとに保存されるので、セットの途中でやめても記録は残り、次回は続きから出題されます。
ただし模擬試験モードは最後まで解くか時間切れになるまで記録されません（本番と同じ扱いにするためです。中断すると採点もされません）。

アプリの版

いまの版: –
新しい版は、アプリを開いたときや戻ってきたときに自動で取り込みます。反映されないときは下のボタンを押してください（学習の記録は消えません）。

学習データ

正答率・習得状態・復習の予定は、この端末のブラウザ内にだけ保存されます。
そのため別の端末では引き継がれず、ブラウザのデータを消すと失われます。下のボタンでファイルに書き出しておけば、別の端末や新しいブラウザで読み込んで続きから学習できます。
全試験ぶんの学習記録を1つのJSONファイルにまとめて書き出します。機種変更の前や、定期的なバックアップに。
書き出したファイルを読み込んで、学習記録を復元します。いまの記録は上書きされます。
