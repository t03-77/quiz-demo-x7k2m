# cert_quiz_app

資格試験の学習ウェブアプリ(開発中)。

- 問題演習、正誤記録と正答率の可視化、読み上げ音声、用語解説、AI連携を予定
- サーバーを持たない静的サイト。学習の進捗は利用者のブラウザ内にのみ保存される
- 公開: GitHub Pages

## 構成

| パス | 内容 |
|---|---|
| `index.html` | アプリ本体(デモ段階では1ファイル完結) |
| `docs/仕様書.md` | 機能仕様 |

## 開発メモ

- 詳細な仕様と進め方は `docs/仕様書.md` を参照
- 問題データは同梱セット(オリジナル問題)と利用者のローカル読み込みセットの二層構成とする
